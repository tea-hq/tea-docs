当 stdin 和 stdout 都连接终端时，运行 `tea` 会进入交互式 TUI。TUI 与 headless CLI 模式属于
同一个 `tea-cli` 产品，共用编码服务、策略引擎、规范会话状态和 SQLite 存储。

```bash
tea --cwd /path/to/project --new
```

在新工作区启动 Tea 前，请先阅读[安装与首次运行](/zh/get-started/install/)。

## 屏幕结构

上方时间线包含已提交 Prompt、助手 Markdown、推理、工具生命周期行、Diff、来源、通知、排队
输入和持久化状态变化。底部编辑器保持稳定，执行过程在上方持续流式更新。

- 提交的 Prompt 会立即出现在时间线中。
- 在出现可见模型输出前，紧凑活动行会显示已观察阶段、耗时和最新工具进度。
- 常规工具调用默认保持紧凑；`Ctrl+G` 切换可用的详细信息。
- `Page Up`/`Page Down` 或 `Shift+Up`/`Shift+Down` 浏览历史且不会丢失草稿；
  `Ctrl+End` 返回实时末尾。
- 助手 Markdown 会渲染为终端结构；HTML 和终端控制序列绝不会被解释执行。

## 编辑器与运行中交互

| 操作 | 默认按键 |
| --- | --- |
| 空闲时提交，或对当前运行进行转向 | `Enter` |
| 插入换行 | `Shift+Enter` |
| 运行中排队后续消息 | `Alt+Enter` |
| 中止当前运行 | `Escape` |
| 取回排队文本 | `Ctrl+R` |
| 选择模型 | `Ctrl+O` |
| 切换推理内容可见性 | `Ctrl+T` |
| 复制最近的助手响应 | `Ctrl+Y` |
| 空闲时退出 | `Ctrl+D` |

转向消息会在下一个安全的模型边界送达；后续消息保留到之后的轮次。按键可在 `tui` 设置对象中
修改；存在歧义的绑定会在配置校验时被拒绝。

## 命令与选择器

输入 `/` 会打开有界补全列表。选择条目只会把它写入编辑器，不会直接执行；提交仍然是显式操作。

常用命令包括：

| 命令 | 用途 |
| --- | --- |
| `/new`、`/resume`、`/session` | 创建、恢复或选择持久化会话 |
| `/model`、`/reasoning` | 选择模型和当前会话的推理强度 |
| `/compact` | 通过已配置的摘要器追加压缩摘要 |
| `/tree`、`/fork <message-id>` | 查看或创建仅追加分支 |
| `/image <path>` | 在模型支持时附加一张明确指定的工作区图片 |
| `/copy` | 复制最近的助手响应 |
| `/mcp` | 查看安全的 MCP 健康状态和冻结别名 |
| `/help`、`/quit` | 显示帮助，或恢复终端并退出 |

可信 Prompt 模板显示为 `/<template>`，可信 Skill 显示为 `/skill:<name>`。项目资源只会在相应的
工作区信任决策后加载。

## 审批

当策略要求授权时，审批面板获得最高输入优先级。它显示已持久化且脱敏的工具、目标、effect、
资源、有效期和参数。选择单次允许、有界会话授权或拒绝前，应先检查完整请求。`Escape` 绝不会
静默拒绝审批。

审批只授权已记录操作，不会沙箱化原生工具或 MCP Server。启用变更型工具前，请阅读
[审批与授权](/zh/safety/approvals/)和[安全边界](/zh/safety/security/)。

## 会话与恢复

`/session` 打开可搜索的会话选择器，`/tree` 打开当前分支选择器。切换时会保留草稿，直到用户
提交。待处理审批和规范记录可在重启后恢复；临时的转向与后续消息显示队列不会持久化。

接下来阅读[会话与恢复](/zh/sessions/sessions/)、
[CLI 模式与命令](/zh/get-started/cli-modes/)和[配置](/zh/configuration/settings/)。

## 设计来源

交互模型借鉴了 OpenAI Codex TUI：语义化时间线 Cell、稳定的底部编辑器、紧凑的工具生命周期行、
实时跟随滚动和聚焦的审批 Overlay。Tea 是独立实现，拥有自己的运行时、协议、渲染组件、命令和
持久化模型。
